Using [Company-Names-Corpus](https://github.com/wainshine/Company-Names-Corpus), we enumerate the characters in the files `Company-Names-Corpus（480W）.txt`, `Organization-Names-Corpus（110W）.txt`, and `Company-Shorter-Form（28W）.txt`, which includes about 6 million company-related proper nouns.  This gave a list of 5403 distinct simplified characters, listed in `wainshine_company_character_frequency.txt` in order of frequency.  We use the characters that occur in 10 or more terms, leaving 4363 simplified characters, as in `wainshine_company_top_chars_unicode_order.txt`.
