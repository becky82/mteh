We download the [Company-Names-Corpus](https://github.com/wainshine/Company-Names-Corpus) corpus which includes about 6 million company-related proper nouns.  Using the files `Company-Names-Corpus（480W）.txt`, `Organization-Names-Corpus（110W）.txt`, and `Company-Shorter-Form（28W）.txt`, we enumerate the Chinese characters using `cat *.txt | grep -oP '[\x{4e00}-\x{9fff}]' | sort | uniq -c | sort -nr | awk '{print $2, $1}'`, giving `wainshine_company_character_frequency.txt` (5403 chars).  This is then sorted by Unicode using `awk '{print $1}' wainshine_company_character_frequency.txt | sort -u`, giving `wainshine_company_chars_unicode_order.txt`.
