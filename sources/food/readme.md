Using [Food-Names-Corpus](https://github.com/wainshine/Food-Names-Corpus), we copy/paste the food-related terms from the Excel spreadsheet `萌名-菜谱生成器V1.1.xlsx` into a temporary file, then use `grep -oP '[\p{Han}]' temp.txt | sort -u` to make a list of the characters therein, namely `wainshine_food_chars_unicode_order.txt` (1182 chars).
