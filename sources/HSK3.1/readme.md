### What is "3.1"?

The HSK 3.0 was officially released in 2021, and many sources (textbooks, apps, the HSK7-9 exam, etc.) used this syllabus (and still do), and have referred to it as the "3.0 syllabus" for years.

However, it looks like Hanban now wish to pretend as if the HSK 3.0 was not released in 2021, and released a modified version of the HSK 3.0 syllabus released in 2025.  To differentiate the two versions, I started calling this 2025 version the HSK 3.1 (since that's how version numbers work).  It would have saved a lot of confusion if they simply called it "3.1", but that's not my decision.

However, since Hanban are sticking to calling it the "3.0 syllabus", in online discussions, I'm leaning more towards calling it the "3.0[2025]" (another name for "3.1" that's more consistent with Hanban's usage).

Also note that both the 2.0 and 3.0[2025] syllabuses are both called the "new HSK" (so be careful e.g. buying textbooks).
