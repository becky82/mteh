The [LWC corpus](https://lwc.daanvanesch.nl/openaccess.php) is a Chinese word corpus derived from Sina Weibo (Chinese "tweets").

The top 20000 "words" from this corpus were used, and all the Chinese characters therein where extracted, resulting in a list of 3585 characters.  [OpenCC](https://github.com/BYVoid/OpenCC) was used to convert the traditional characters to simplified characters, which resulted in a list of 4130 characters.
