The [LWC corpus](https://lwc.daanvanesch.nl/openaccess.php) is a Chinese word corpus derived from Sina Weibo (Chinese "tweets").  From the LWC corpus file `words_types.txt` (inside `LWC-words.zip`) we generate a frequency table using `awk -F',' '{gsub(/"/,""); print $2 " " $4}' words_types.txt | sort -k2,2nr`, giving `LWC_words_frequency_order.txt` (1379769 terms).  This was converted to a character frequency table using `perl -CSD -lane '$count{$_}+=$F[1] for $F[0]=~/\p{Han}/g; END { print "$_ $count{$_}" for sort {$count{$b}<=>$count{$a}} keys %count }' LWC_words_frequency_order.txt` (which uses [OpenCC](https://github.com/BYVoid/OpenCC) to convert characters to simplified), giving `LWC_chars_frequency_order.txt` (12049 chars).  We then use `head -n 5000 LWC_chars_frequency_order.txt | awk '{print $1}' | sort -u` to select the top-5000 characters, given in `LWC_chars_top5000_unicode_order.txt` (5000 chars).
