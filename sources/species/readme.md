Using [Species-Names-Corpus](https://github.com/wainshine/Species-Names-Corpus), we enumerate the characters in the file `Species-Names-Corpus（20W）.txt`, which includes about 214,000 species names.  This gave a list of 4086 distinct simplified characters, listed in `wainshine_species_character_frequency.txt` in order of frequency, and in `wainshine_species_chars_unicode_order.txt` in unicode order.
