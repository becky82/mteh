From [Species-Names-Corpus](https://github.com/wainshine/Species-Names-Corpus), we use `Species-Names-Corpus（20W）.txt`, which includes about 214,000 species names.  We use the command `perl -CSD -lane '$count{$_}++ for /\p{Han}/g; END { print "$_ $count{$_}" for sort {$count{$b}<=>$count{$a}} keys %count }' 'Species-Names-Corpus（20W）.txt'` to enumerate the characters in the file, giving `wainshine_species_character_frequency.txt` (4086 chars).  The command `awk '{print $1}' wainshine_species_character_frequency.txt | sort -u` was used to sort the characters by Unicode, giving `wainshine_species_chars_unicode_order.txt` (4086 chars).
