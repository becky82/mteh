[THUOCL](https://github.com/thunlp/THUOCL) (Tsinghua University Open Chinese Lexicon) is a Chinese word frequency corpus.  It enumerates the number of times words appear within documents sourced from CSDN博客 (blogs; 3,785,976 docs), 新浪新闻 (news 8,421,097), and 搜狗语料 (Chinese text corpus; 729,008,561 webpages), totally 741 million documents.

The THUOCL data files were merged using `awk '{sum[$1] += $2} END {for (w in sum) print w, sum[w]}' *.txt | sort -k2,2nr`, giving `THUOCL_full_list.txt` (111796 entries).  The command `awk '{for (i=1;i<=length($1);i++) sum[substr($1,i,1)]+=$2} END {for (c in sum) if (sum[c]>=741 && c ~ /[一-龥]/) print c, sum[c]}' THUOCL_full_list.txt | sort -k2,2nr | awk '{print $1}'` was then used to extract the characters with total frequency >= 741 (i.e., these characters occur in at least 1 in 1000000 documents), giving `THUOCL_741docs_chars_frequency_order.txt` and `THUOCL_741docs_chars_unicode_order.txt` when sorted according to Unicode (3469 chars).

In this list, the characters 魟 and 鮰 are rare traditional characters; in fact 魟 should be 𫚉, and 鮰 doesn't seem to have a simplified version in Unicode currently.  However, for the purposes of MteH, we can ignore this problem as these characters are too rare to be relevant.
