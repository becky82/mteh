From [Medical-Names-Corpus](https://github.com/wainshine/Medical-Names-Corpus), which includes about 2.6 million medical organization names, we use `grep -oP '[\x{4e00}-\x{9fff}]' Medical-Org-Names-Corpus（260W）.txt | sort | uniq -c | sort -nr | awk '{print $2, $1}'` to enumerate the characters in the file `Medical-Org-Names-Corpus（260W）.txt`, giving `wainshine_medical_character_frequency.txt` (4826 chars).  The command `awk '{print $1}' wainshine_med-orgs_character_frequency.txt | sort -u` is used to convert it into Unicode order, as in `wainshine_med-orgs_chars_unicode_order.txt` (4826 chars).
