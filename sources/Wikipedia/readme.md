A top-10000 most frequenct Chinese character list for Wikipedia (2015) was downloaded from [Chinese Character Frequencies](https://czielinski.github.io/hanzifreq/hanzifreq/output/frequencies.html) (which was generated using [hanzifreq](https://github.com/czielinski/hanzifreq)).

From the top-4500 characters therein, [OpenCC](https://github.com/BYVoid/OpenCC) was used to convert the traditional characters to simplified characters, which left 3476 unique characters, namely `Wikipedia_chars_top4500_simplified_unicode_order.txt`.
