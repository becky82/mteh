We download and extract the Chinese characters listed in Singapore's Ministry of Education's 《欢乐伙伴》小学华文生字表 (2015; [pdf](https://www.moe.gov.sg/-/media/files/primary/2015characterlistprimarychinese.pdf); [archive](https://web.archive.org/web/20240120172307/https://www.moe.gov.sg/-/media/files/primary/2015characterlistprimarychinese.pdf)) which lists Chinese characters at different levels of primary school.  We can extract the characters from this pdf by copy/pasting it into a temporary text file `temp.txt`, and using the command `grep -oP '[\p{Han}]' temp.txt | sort -u`.

This gives a list of 1655 characters, namely `Singapore_chars_unicode_order.txt`.
