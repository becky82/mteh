From the [Chinese-Names-Corpus](https://github.com/wainshine/Chinese-Names-Corpus), we use the `Chinese_Names_Corpus（120W）.txt` which contains 1,200,000 distinct Chinese names and enumerate all the characters therein (converting any traditional characters to simplified using [OpenCC](https://opencc.byvoid.com/)).  This resulted in a list of 2269 characters, as in `CNC_chars_unicode_order.txt`.
