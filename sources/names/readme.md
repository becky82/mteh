We download the [Chinese-Names-Corpus](https://github.com/wainshine/Chinese-Names-Corpus) corpus which contains 1,200,000 distinct Chinese names.  Using the file `Chinese_Names_Corpus（120W）.txt`, we enumerate the Chinese characters using `cat Chinese_Names_Corpus（120W）.txt | grep -oP '[\x{4e00}-\x{9fff}]' | sort | uniq -c | sort -nr | awk '{print $2, $1}'`, giving `CNC_character_frequency.txt` (2270 chars).  This is then sorted by Unicode using `awk '{print $1}' CNC_character_frequency.txt | sort -u`, giving `CNC_character_chars_unicode_order.txt` (2270 chars).
